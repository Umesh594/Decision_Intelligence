# Resume Bullets

- Designed and implemented a concurrent Monte Carlo simulation engine in Java: a correctly-bounded `ThreadPoolExecutor` runs independently-seeded `SplittableRandom` batches, a scrambled Sobol low-discrepancy sequence drives quasi-random variance reduction on the dominant risk factors, and a lock-free Welford online-variance accumulator (CAS-based) detects statistical convergence to stop early instead of running a fixed iteration count.
- Built idempotent, resumable simulation runs backed by per-path Postgres checkpoints, keyed by a client-supplied idempotency key or a SHA-256 request fingerprint, so retried or resumed requests provably never re-run a completed batch or double-count its contribution (covered by dedicated resume/idempotency tests).
- Built an AI Decision Consequence Simulator with Java, Spring Boot, React, PostgreSQL, Redis, Docker and Kubernetes to compare career decision paths through calibrated Monte Carlo simulation and probabilistic salary-goal forecasting.
- Integrated Groq API to generate traceable, non-advisory explanations from simulation outcomes, assumptions, downside risk and confidence bands, with a deterministic simulation-only fallback when no API key is configured.
- Externalized the calibration layer (city cost index, company tier, role level, market demand, interview conversion, emergency fund strength, skill demand, historical salary growth) to Spring `@ConfigurationProperties`-backed `application.yml`, replacing hardcoded lookup tables with a versionable, per-request-overridable baseline dataset.
- Implemented production backend patterns including REST APIs, validation, API-key security, Flyway migrations, OpenAPI documentation, actuator health checks, Docker images and CI/CD through GitHub Actions, Jenkins and Azure DevOps.
- Fixed a transaction-scoping bug where CPU-bound simulation work held a pooled database connection open for its full duration; split it into short, explicit transactions around the database reads/writes only.
