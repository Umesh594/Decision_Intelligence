# Resume Bullets

- Built an AI Decision Consequence Simulator with Java, Spring Boot, React, PostgreSQL, Redis, Docker and Kubernetes to compare career decision paths through calibrated Monte Carlo simulation and probabilistic salary-goal forecasting.
- Integrated Groq API to generate traceable, non-advisory explanations from simulation outcomes, assumptions, downside risk and confidence bands.
- Added a calibration layer for city cost index, company tier, role level, market demand, interview conversion, emergency fund strength, skill demand and historical salary growth to make forecasts more realistic for business use cases.
- Implemented production backend patterns including REST APIs, validation, API-key security, Flyway migrations, OpenAPI documentation, actuator health checks, Docker images and CI/CD through GitHub Actions, Jenkins and Azure DevOps.
- Added enterprise integration readiness for JIRA and Azure DevOps workflows, enabling decision simulations to be linked with stakeholder review and delivery tracking processes.
